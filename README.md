# Four Souls Randomizer

The character based on "Tainted Lazarus" has double-sided artwork, which means it's impossible to select a character at random from a hand.
I wanted to fix that by making my own character selector for the game.

##Run through terminal.
- Download python file
- Use cd command to travel to where it's been downloaded
- python <filename> to run
